# 路线图

按“能不能让一个人愿意在里面走十分钟”排序。

## 近期（v3.x）

- [ ] **NPC 入场**：小茉（18 岁，坦率冒失）、小橘（21 岁，稳重但依赖）。
      需要：`scene.json` 加 NPC 物件、`game.html` 加对话系统（E 触发、逐字、可跳过、可分支）。
- [ ] **立绘与对话框**：像素立绘 + 半透明对话框，保留“视觉小说”质感。
- [ ] **地标补充**：中区/东区的食堂、宿舍、医院、礼堂各补一个，共 18 个左右。

## 中期（v4）

- [ ] **镜渊专属景观**：东区上空浮岛、中区月面广场、也西湖“倒影世界”入口。
      做法：额外的 sprite 层 + 镜渊模式下才绘制的装饰层；可进入的场景用独立 `scene` 遮罩。
- [ ] **场景切换**：把“可进入建筑”做成独立小场景（图书馆阅览室、地下通道内部）。
- [ ] **存档与图鉴**：去过的地方、遇到的人、看到的风景，做成“漫游日志”。
- [ ] **环境音**：水岸、操场、地下通道各自的底噪 + 步行声。

## 远期

- [ ] 移动端手势（单指行走、双指缩放）与手柄。
- [ ] 多校区扩展：南区、北区、高新校区。
- [ ] 季节与天气（雨、雪、樱花），复用同一套图层与调色。
- [ ] 玩家自建地标（导出/导入 `scene.json` 片段）。

## 已否决的方向

- 任务系统、等级、战斗：与设定冲突（系统只传感官信号，屏蔽痛觉）。
- 实时联网多人：会破坏“一个人戴上硬体走一走”的孤独感；如需多人，做成“同一张图的异步痕迹”（留言/脚印）。
