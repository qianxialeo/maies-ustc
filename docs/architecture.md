# 架构说明

## 1. 坐标系统

所有几何先换算成“本地米制”，再投影到像素：

```python
x = (lon - 117.255) * 94650      # 东向，米
y = (lat - 31.84)  * 110900      # 北向，米
```

投影（`source/make.py` 顶部）：

```python
S  = 3.1     # 东西向：像素/米
VS = 0.80    # 旋转后纵轴相对横轴的压缩系数
K  = S*VS    # 南北向：像素/米
HZ = 1.0     # tr 的高度偏移倍率，也用于普通楼宇的投影高度估计（阴影）
TH = math.radians(1.5)  # 先在地面内旋转，再投到画面
```

- `tr(x, y, h)` 先用 `rw` 得到旋转后的 `X, Y`，再返回 `round(S*X + TX), round(TY - K*Y - h*HZ)`。两条地面轴每米分别占 3.10 和 2.48 个原生像素，北方接近屏幕上方。
- 建筑先把占地投到屏幕，再由 `facade()` 从屏幕 y 坐标减去像素高度。通用楼宇通常按每层 10.6 px 绘制，专属建筑另定。这套美术尺寸不足以还原实际楼高或相机俯角。[生成器](../source/make.py)

## 2. 构建两段式

### 2.1 `source/make.py` —— 生成图层与场景

1. 读 `data/campus3.osm`，建三校区多边形，并把肥西路 / 金寨路的街块并进陆地（`camp`）。
2. 铺底：海面渐变、陆地台基、草地噪点。
3. 画地面：广场、道路（按等级分宽、主干道加虚线）、水系与岸线、建筑投影、校际连接细节
   （肥西路斑马线、金寨路地下通道）、西区田径场与球场。
4. 生成建筑精灵：按 OSM 名称/楼层/面积选风格（`STY`/`OVR`），逐栋扰动色相，
   画立面（7 种开窗模式）与屋面（平/坡/锯齿），最后裁切成 sprite 并记录锚点与遮挡值。
5. 种树、摆路灯长凳、探照灯，按避让集合（建筑、水面、道路、广场）排除。
6. 用相同水面生成通行掩码。东区的水域多边形关系保留亭岛的内环，两段步桥的可行走区域叠回湖面。`art/nav.png` 中白色可行走。
7. 写 `art/scene.json`：`{w, h, sprites, objects, marks, lakeside}`。

`objects` 每条是 `[sprite名, x, y, depth]`，`depth` 取脚印最低点（屏幕 y），
游戏按它做前后遮挡排序。

### 2.2 `source/bundle.py` —— 打包

把 `ground.png` / `nav.png` / 缩略图 / 全部 sprite 以 base64 内嵌进 `game.html` 的
`<script id="assets" type="application/json">`，输出单文件 `中科大像素漫游.html`，
顺带合成 `中科大全图.png` 与湖畔两倍放大图。

## 3. 游戏外壳 `source/game.html`

- 画布按 `SCALE=[1,1.6,2.25,3]` 的倍率绘制并拉伸到视口，禁用图像平滑以保留像素边缘。
- 每帧：取相机矩形 → 画地面 → 画水波 → 按 depth 排序画物件（人物插在正确深度）→ 覆盖层。
- 点击地面后角色朝目标直走，每一步用 `valid()` 检查掩码。地标和小地图跳转另用 `safe()` 向外逐圈寻找可用落点。
- 镜渊模式：给 `ctx.filter` 设冷色滤镜后绘制地面与物件，随后叠加星点、月亮、流萤与夜色渐变。

## 4. 数据流约定

- 新增物件必须同时给出 `depth`，否则遮挡会错。
- 精灵原点在图片左上角；建筑精灵的“脚印”在图片底部，因此 `y + height` 约等于建筑南缘。
- 修改投影参数（`S/VS/HZ/TH`）后，所有精灵与掩码必须整体重建，不能只改一处。
