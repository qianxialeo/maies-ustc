# 数据与授权

## 数据来源

- `data/campus3.osm`：西区（way 259860583）、中区（298734692）、东区（262614785）及其周边
  建筑、道路、水系、球场，来自 OSM 主 API（bbox `31.8335,117.2450,31.8445,117.2690`）。
- `data/west.osm`：早期西区节选，保留用于对照与旧版生成器。
- 校准基准点：`lon 117.255`、`lat 31.84`，换算系数 `94650` / `110900` m·deg⁻¹。

## 更新数据

```bash
python scripts/fetch_osm.py
python scripts/build.py
```

抓到的文件直接覆盖 `data/campus3.osm`。若 OSM 主 API 限流，脚本会自动尝试 Overpass 镜像。
更新后请重点检查：新增建筑是否落在 `camp` 内、道路是否把田径场切断、地下通道是否仍连得上。
