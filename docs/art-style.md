# 美术规范

## 1. 网格与比例

- 基准：**3.1 px = 1 m**（东西向）；南北 0.78，竖向 1.16。
- 所有绘制以整数像素落笔，禁止半像素；曲线用采样点 + 自写光栅化。
- 人高 ≈ 14 px（`person()`），树 ≈ 76–88 px，路灯 ≈ 30 px。

`make.py` 里的连续光栅化：


新增斜线（车道线、桥栏杆、屋脊、分道线）必须走这套函数。

## 3. 调色板

整体偏粉彩、低饱和，避免纯黑纯白。常用基色：

| 用途 | 参考色 |
| --- | --- |
| 草地 | `#aab786` `#bfc593` `#c8c99a` |
| 水 | `#548e88` `#66a292` `#7eae98` |
| 铺装 / 道路 | `#d3c6a4` `#b9b9a3` `#98998c`（主干道） |
| 跑道 | `#a2593f` + `#b26a4c` 颗粒 |
| 草皮 | `#6d9560` / 条纹 `#739c65` `#678f5a` |
| 屋顶 | `#bcc0ae` 一类浅灰暖色 |
| 夜色（镜渊） | 由滤镜生成，不单独上色 |

## 4. 建筑分型

| 风格键 | 用于 | 特征 |

| `lib` | 图书馆 | 红砖塔楼 + 米白横带 + 白檐口 |
| `teach` | 教学楼 | 浅米白 + 通长横向窗带 |
| `lab` | 实验/研究楼 | 冷灰 + 竖向窄窗 |
| `dorm` | 宿舍 | 暖白 + 阳台栏板 |
| `canteen` | 食堂 | 暖砂色 + 玻璃幕墙 |

开窗模式：`grid`（点窗）、`ribbon`（横带）、`slit`（竖缝）、`curtain`（幕墙）、
`balcony`（阳台）、`fin`（竖向壁柱）。

## 5. 非同质化规则

1. 按功能选风格，不随机贴色。
2. 单栋在基色上做 ±6% 明度、4–16% 环境色混入。
3. 屋面按体量选择：小体量近矩形 → 坡屋顶；大跨 → 锯齿；其余平屋顶 + 女儿墙 + 设备。
4. 每栋至少在屋顶放 1–3 个排风/检修口；大面积屋顶加太阳能板或机房。

## 6. 新增物件的检查表

- [ ] 落点在 `nav` 之外（建筑/水面）或明确加了避让
- [ ] `depth` 用的是屏幕 y（脚印处）
- [ ] 在 1× 与 2.25× 下都不糊、不出半像素
- [ ] 颜色与相邻物件有区分（同色系请改明度）
